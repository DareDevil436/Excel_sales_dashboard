📌 Project Overview
This project focuses on analyzing sales data using Microsoft Excel and presenting insights through an
interactive dashboard. The goal is to demonstrate core data analyst skills such as data cleaning, KPI
calculation, pivot table analysis, and dashboard storytelling.
This project is designed especially for a fresher / junior data analyst portfolio.
🧾 Dataset Description
The dataset represents transactional sales data and includes the following fields: - Order_ID - Order_Date 
Customer_Name - City - Product - Category - Quantity - Unit_Price - Total_Sales
The data was used to analyze revenue trends, customer behavior, and product performance.
